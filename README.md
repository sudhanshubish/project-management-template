# Project management templates

Minimal project-memory files for Cursor, Codex, and Claude.

| File | Purpose |
| --- | --- |
| `PROJECT_CONTEXT.md` | Durable facts, links, plan, decisions |
| `PROJECT_STATUS.md` | Current work, PRs, open questions, activity log |
| `AGENTS.md` | Codex / generic agent entry point |
| `CLAUDE.md` | Claude entry point |

Placeholders:

- `{{PROJECT_NAME}}` — human project title
- `{{DATE}}` — ISO date `YYYY-MM-DD`

Install with the `/project-setup` skill.
