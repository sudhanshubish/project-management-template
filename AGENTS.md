# Agent Instructions

Before contributing:

1. Read `PROJECT_CONTEXT.md` for durable project knowledge.
2. Read `PROJECT_STATUS.md` for the current handoff and next actions.
3. Verify time-sensitive claims, especially PR and CI status, at their source.

After meaningful work:

- Update `PROJECT_STATUS.md` with outcomes, evidence, current state, and next
  actions.
- Update `PROJECT_CONTEXT.md` only when durable facts, plans, or accepted
  decisions change.
- Use ISO dates and explicit links. Write `Unknown` instead of guessing.
- Keep one canonical source for each fact; cross-reference rather than copy.
- Never record credentials, tokens, private keys, or other secrets.
